# SpeedTest

Консольный скрипт на Python, который замеряет скорость скачивания: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый, считает среднее время запроса, общий объём скачанных данных и итоговую скорость.

## Требования

Python 3.9 или новее. Сторонние библиотеки не нужны, используется только стандартная библиотека.

## Запуск

```bash
git clone https://github.com/Rdil1/SpeedTest.git
cd SpeedTest
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://raw.githubusercontent.com/python/cpython/main/Objects/unicodeobject.c
```

Необязательные параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-n`, `--requests` | 10 | количество запросов |
| `-t`, `--timeout` | 30 | таймаут одного запроса, секунды |

## Пример вывода

```
URL: https://raw.githubusercontent.com/python/cpython/main/Objects/unicodeobject.c
Запросов: 10

[ 1/10]  461.23 КБ за 0.304 с
[ 2/10]  461.23 КБ за 0.086 с
...

Успешных запросов:   10 из 10
Скачано всего:       4.61 МБ (4612270 байт)
Среднее время:       0.112 с
Скорость скачивания: 32.94 Мбит/с (4.12 МБ/с)
```

## Единицы измерения

Основная единица скорости — **мегабиты в секунду (Мбит/с)**, как у провайдеров и популярных спидтестов. Рядом для удобства указаны **мегабайты в секунду (МБ/с)**.

Используются десятичные приставки: 1 Мбит = 1 000 000 бит, 1 МБ = 1 000 000 байт, 1 КБ = 1 000 байт. Время — в секундах.

## Как считается

Время запроса измеряется от его отправки до получения последнего байта тела ответа, то есть включает DNS, установку соединения и TLS. Тело читается целиком, поэтому замер отражает полное скачивание, а не только заголовки.

Среднее время — сумма времени успешных запросов, делённая на их количество. Скорость — общий объём скачанных байт, делённый на суммарное время успешных запросов.

Чтобы замер был честным, скрипт отправляет `Cache-Control: no-cache` (просит не отдавать копию из кэша) и `Accept-Encoding: identity` (без сжатия, считаются реальные байты ресурса).

## Обработка ошибок

Неудачный запрос (HTTP-ошибка, таймаут, обрыв соединения) выводится в консоль, а скрипт продолжает работу; статистика считается по успешным запросам.

Коды выхода: `0` — все запросы успешны; `1` — ни один запрос не удался; `2` — неверные аргументы; `3` — часть запросов завершилась ошибкой; `130` — прервано через Ctrl+C.

## Ограничения

Результат зависит от сервера: если он медленный или далеко, скрипт покажет его скорость отдачи, а не пропускную способность канала. Для точного замера стоит брать большой файл (десятки мегабайт) с быстрого CDN. Запросы идут в один поток, поэтому многопоточный спидтест на том же канале может показать больше.
